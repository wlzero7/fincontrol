# 💰 FinControl v6

Sistema de controle financeiro desenvolvido por William Campos.

## 📌 Sobre o projeto

O FinControl é uma aplicação web criada para auxiliar usuários no gerenciamento de finanças pessoais de forma simples e intuitiva.

Este é o maior projeto desenvolvido por mim até o momento, reunindo conceitos de:

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Composer
- PHPMailer
- Hospedagem Web

## 🚀 Funcionalidades

✅ Cadastro de usuários

✅ Login seguro

✅ Dashboard financeiro

✅ Controle de receitas

✅ Controle de despesas

✅ Categorias personalizadas

✅ Relatórios financeiros

✅ Exportação CSV

✅ Geração de PDF

✅ Recuperação de acesso por e-mail

## 🛠 Tecnologias utilizadas

- PHP 8
- MySQL
- HTML5
- CSS3
- JavaScript
- Composer
- PHPMailer
- InfinityFree
